## 二、四关的原著依据与军令设计

### 第 1 关 · 汜水关（原著第 1–6 章）

**情节**：关羽临阵"逃跑"去拉冲刺距离 → 马哥跑吐白沫 → 青龙直径 3 米 → 华雄强提至 17 倍力量（走马灯/羁绊之力）→ **一刀斩华雄 + 青龙贯穿华雄军阵** → 袁绍当即下令「**全军出击！攻城！！！**」→ 第6章开头「**盟军成功攻破汜水关**」

| 阶段 | 军令 | 条件 |
|---|---|---|
| 1 | 温酒斩华雄 | `kill_commander` |
| 2 | 劈关夺门（对准城门格、满 10 格蓄力） | `break_gate` |

> 关键：**先斩将、后破关**，这是原著明写的两段式。破门不再靠"打主将附带"，必须把青龙斩劈在城门上。

### 第 2 关 · 虎牢关（原著第 10–17 章）

**情节**：李儒随军；武安国挑战被斩 → 公孙瓒跟踪箭 → 张飞咆哮破铁皮 → 关羽骑赵云连夜跑九个时辰拉出十米青龙 → 撞飞吕布 → **吕布撤回虎牢关** → 第17章「只要董卓想坚守虎牢关，盟军**不可能**打进去」→ 第22章才被攻破（**董卓主动弃守**）

| 阶段 | 军令 | 条件 |
|---|---|---|
| 1 | 顶住虎牢关前（3 回合） | `survive_turns: 3` |
| 2 | 击退吕布（不是斩杀；赤兔马把他叼走） | `defeat_commander` |

> 关键：这关**不应该有破城阶段**——原著里虎牢关没被攻下来。

### 第 3 关 · 谯县（原著第 30 章 + 第 181 章）

**情节**：刘备亲赴谯国谯县招许褚，许褚"一无军功，而无绝技"，刘备说「你没有绝技我可以让人帮你觉醒」→ 许褚加入；**第181章标题即「许褚觉醒」**（裸衣）

| 阶段 | 军令 | 条件 |
|---|---|---|
| 1 | 肃清围困许褚的黄巾乱兵 | `kill_minions` |
| 2 | 把裸衣许褚打到三成血以下逼其停手，**别打死** | `recruit_at_hp: 0.3` |

### 第 4 关 · 泰山郡（原著第 78–95 章）

**情节**：郭嘉围昌豨山砦（易守难攻）→ 昌豨向臧霸求救 → 臧霸拖延 → 刘备方案是第88章明写的「**将臧霸打回泰山东边的琅琊郡即可**」

| 阶段 | 军令 | 条件 |
|---|---|---|
| 1 | 击破据守山砦的昌豨 | `kill_target: changxi` |
| 2 | 击退臧霸（打回琅琊郡） | `defeat_commander` |

## 三、条件引擎支持的类型（`scripts/core/objectives.gd`）

| type | 参数 | 含义 |
|---|---|---|
| `kill_commander` | — | 敌方主将阵亡 |
| `defeat_commander` | — | 击退主将（同血量归零，但剧情上按"败走"处理） |
| `break_gate` | — | 城门被劈开 |
| `survive_turns` | `value` | 坚守 N 回合 |
| `kill_all` | — | 全歼敌军 |
| `kill_minions` | — | 除主将外杂兵清光 |
| `kill_target` | `target` | 指定单位倒下 |
| `recruit_at_hp` | `target`, `ratio` | 目标血量降到 ratio 以下（一击致死也算达成） |

关卡没写 `stages` 时，按 `win_condition` 自动合成单阶段（向后兼容）。

## 五、按需提取原文的方法（避免整本读）

```bash
cd "D:/huanglei/deepseek/game/zcode项目/docs"
python -c "
import re
t = open('魂穿刘关张，诸侯们被整麻了.txt','rb').read().decode('gb18030')
titles = list(re.finditer(r'第\s*(\d+)\s*章[^\n]{0,40}', t))
segs = {}
for i, m in enumerate(titles):
    n = int(m.group(1))
    end = titles[i+1].start() if i+1 < len(titles) else len(t)
    segs[n] = t[m.start():end]
want = [30, 181]          # 只取需要的章节号
for n in want:
    print('===== 第%d章 =====' % n)
    print(segs.get(n, '(缺失)')[:3000])
"
```

```bash
grep -a "臧霸\|琅琊" 魂穿刘关张，诸侯们被整麻了.txt | head -30
```
