## 三、本轮（2026-09-19）在第一关修掉的问题

| # | 问题 | 性质 |
|---|---|---|
| 1 | 军令文案说华雄"每斩一将叠一层"，实现却是**每回合 +1** | 文案错误 |
| 2 | 劈城门要求**紧贴城门**，与"12 格直线贯穿"的技能设定矛盾 → 蓄满 10 格也劈不到 | 设计缺陷 |
| 3 | 蓄力不足点城门**照样消耗行动** → 误点一次白丢整回合 | 体验缺陷 |
| 4 | **开局第 1 回合从不走 `_begin_player_turn()`** → `turn:1` 事件是死数据，桃园结义/玉米种子回血、压力旗标第 1 回合全部跳过 | 架构缺陷 |
| 5 | 武安国剧情"吐血脱力"但单位满血（第 2 关，同批修复） | 剧情与状态脱节 |

> 修 #4 时特别注意：`_ready` 里原本硬编码播一句 `chapterN_open`，
> 看起来"对白正常"，所以这个 bug 藏了很久 —— 事件系统整条链路在第 1 回合是断的。

## 四、手工验收清单（打开游戏逐条点）

1. **全屏**：F11 进全屏 → 进军第一关 → 画面居中铺满（不是挤在左下角）
2. **序章**：首次进第一关应播序章；Space 逐句、点"跳过"直接进关；**重进不再播**
3. **空格**：什么都不做直接按空格 → 弹"还有 N 人未行动"警告；**再按一次**才切敌方回合
4. **劈门（正路）**：关羽绕场蓄到 10 格 → 走到与城门同一行/列且距离 ≤ 贯穿格数 → 点城门 → 破门 + 声望 +500
5. **劈门（错路）**：蓄力只有 5 格时点城门 → 提示"力道不足"，且**关羽这回合还能继续行动**
6. **咆哮**：张飞点咆哮 → 连点 Space 到 14 字 → 附近**自己人也被震晕**（戴耳塞可免疫）
7. **战败**：故意让我方全灭 → 失败对白播完应**自动回主菜单**（不是卡死）
8. **通关**：走完两阶段 → 结算面板 → 战利品进背包 → 主菜单显示已通关

第 4、5 条是本轮改动的重点，建议优先确认手感。

## 五、加新测试的规矩

1. **走真实入口**：涉及输入/状态机的验证必须调 `_handle_click()` / `_input()`，
   不要直接调 `_do_move()`（bug 常常就藏在点击分派那一层，绕过它会漏判）
2. 命名以 `test_` 或 `probe_` 开头才会被 `run_all_tests.py` 自动发现
3. 失败输出用 `[FAIL] 描述` 或 `❌ 描述`，便于脚本抓取
4. **先改《游戏设计文档》的期望行为，再改代码，最后同步本清单**
