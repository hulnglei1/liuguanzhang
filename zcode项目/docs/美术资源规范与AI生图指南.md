# 美术资源规范与 AI 生图指南

> 适用版本：`zcode项目` @ 2026-09-17
> 目标：把当前"色块 + 发光特效"的原型画面，升级成有卖相、且风格统一的正式美术资源。

---

## 一、先给结论

| 问题 | 结论 |
|---|---|
| 有没有现成轮子？ | **有一套，但风格不匹配**。三国题材免费素材确实存在（见第三节），但清一色是 **16×16 像素风**；本项目是 1280×720 下 **52px 格子 + 程序化发光/震屏/全屏特效**，硬套像素素材会让"格子里的点阵小人"和"发光的青龙"撕裂成两种画风 |
| 那该怎么办？ | **不走像素风，走 AI 生图 + 统一风格锚**。地形/建筑/图标这类"配角"可以用现成素材或 AI 生成后统一调色板；武将、小兵、立绘必须自产（要贴合小说人物形象，现成素材对不上） |
| 谁先做？ | 立绘（性价比最高，代码接口已就绪）→ 战场单位（武将与兵种）→ 地形建筑 → UI 图标 → 音效 |

## 二、现状盘点：哪些是色块，哪些已经能看

| 模块 | 当前实现 | 需要替换？ |
|---|---|---|
| 战场地形 | 程序绘制网格 + 高地/障碍色块 | ✅ 需要（贴图） |
| 武将单位 | 色块 + 文字名牌（`scripts/battle.gd` 里程序生成） | ✅ 需要（立绘式小人） |
| 小兵单位 | 同上，同色不同形 | ✅ 需要 |
| 战场特效 | 程序生成的青龙、音波圈、爆裂、残影、震屏、全屏闪光 | ⭕ **保留**（这是目前最强的部分，别动） |
| 对话框 | 墨玉金边面板（程序绘制 StyleBox） | ⭕ 保留，可加立绘 |
| 立绘 | **无**（代码已预留接口） | ➕ 新增 |
| UI 图标 | 文字 + emoji 字符（⚔️ ✨ 🛡️） | ⚠️ 可选替换（emoji 依赖系统字体，导 Web 会不稳） |
| 主菜单 | 程序绘制卡片 + 金色描边 | ⭕ 保留，可加背景图 |

**关键判断**：特效体系是程序化的（`_spawn_dragon` / `_spawn_shockwave` / `_spawn_seven_dash` 等），它决定了整套美术必须是**"发光、有体积感、偏写实手绘"**的路子 —— 像素点和矢量扁平都撑不住这种特效。这是选风格的第一约束。

| 来源 | 内容 | 许可证 | 能不能用 |
|---|---|---|---|
| [B.B.Bits 三国系列](https://bbbits.itch.io/three-kingdoms-peach-garden-tileset) | 桃园场景 tileset（16×16，屋顶/土墙/家具/装饰）、三国 NPC 行走图 8 角色 | 免费商用；**禁止作为 AI 训练数据、禁止转售/再分发** | ⚠️ 仅作**风格参考**（看它是怎么画中式瓦当、土墙的），不建议直接用（像素风不匹配） |
| [Niao_K 中式古风角色包](https://niao-k.itch.io/pixel-art-ancient-chinese-character-series-pack-3) | 16×16 四向行走 + **立绘 + 侧视战斗序列**（idle/出击/受击/技能/胜利/死亡…） | 免费商用，可修改；禁止转售/NFT | ⚠️ 同上。但它的**动作列表值得抄**：战棋单位建议的动作集就该是这一套 |
| [itch.io 中式古风 tileset 合集](https://itch.io/s/166761/pixel-art-chinese-ancient-style-tileset) | 多套中式室内外 tileset | 各包不同，逐个看 | ⚠️ 参考为主 |
| Kenney（CC0） | UI 套件、图标、音效 | **CC0，无限制** | ✅ **UI 图标和音效建议直接用**（风格中性，无版权风险） |
| OpenGameArt / OpenGameGraphics | 综合素材库 | CC0/CC-BY 混合，逐个看 | ✅ 找音效、UI 边框可用 |

**结论**：地形和人物的"轮子"要么风格不匹配、要么带再分发限制，**自产更省心**；UI 图标和音效用 CC0 素材最划算。

## 四、代码侧已就绪的接口（补图不用改代码）

### 4.1 立绘（已完成）

```
放置路径：res://assets/portraits/
文件名：  {unit_id}_{emotion}.png
```

- `unit_id` 取值：`liubei` `guanyu` `zhangfei` `zhaoyun` `gongsunzan` `wuanguo` `xuchu` `huaxiong` `lubu` `zangba` `caocao` `yuanshao`
- `emotion` 取值：`normal` `angry` `happy` `sad` `shock`（找不到对应表情会自动回退 `_normal`）
- 加载器：`scripts/ui/portrait_loader.gd`；**缺图时自动隐藏，不报错**，可以一张一张慢慢补
- 已接入：序章过场（`prologue.gd`，右下 360×480 框）+ 战斗对话（`battle.gd`，左下 300×400 框）
- 对话 JSON 可显式指定：`{"speaker":"关羽","text":"…","portrait":"guanyu","emotion":"angry"}`；不写则按说话人自动匹配，`mood` 字段会映射成表情

**规格**：透明 PNG，**900×1200（3:4）**，人物居中、脚底贴画布底边、头顶留 8% 空。
> 为什么是 3:4：对话框上方的立绘位是竖向的；统一比例后换人不会跳动。

### 4.2 战场单位（建议方案，待实现）

```
文件名：  {unit_id}.png
建议规格：透明 PNG，192×192（2× 于 52px 格子，缩放有富余），人物脚底对齐画布底边居中
```

### 4.3 地形与建筑（建议方案）

## 五、AI 生图规范（核心）

### 5.1 风格锚（Style Anchor）—— 每次出图都必须带

**中文版**（给国内工具：即梦 / 通义万相 / 可灵）：

```
中国风水墨工笔混合风格，三国题材战棋游戏美术，墨玉青绿主色调，
金色描边勾线，体积光，厚涂质感，暗部压深，高光集中，
画面干净无背景杂物，无文字，无logo，无边框
```

**英文版**（给 Midjourney / SD / Flux）：

```
Chinese ink-wash combined with semi-realistic digital painting,
Three Kingdoms era tactical RPG art, jade-green and ink-black palette,
gold rim light and outline, volumetric lighting, thick-paint rendering,
clean composition, no text, no logo, no border, no watermark
```

**固定负面词**：

```
lowres, blurry, extra fingers, extra limbs, bad anatomy, jpeg artifacts,
signature, watermark, text, ui, frame, border, pixel art, flat vector, chibi
```

> 最后三个负面词是关键：**必须排掉"像素/扁平/二头身"**，否则风格会飘回不兼容的方向。

### 5.2 三条保一致性的硬规则

1. **一次定锚，全程续用**：先用 5-8 张出图确定基调（挑 1 张当"参考图"），之后所有图都带上同一段风格锚 + 这张参考图（MJ 用 `--sref`，SD 用 IP-Adapter / reference-only）。
2. **固定色板**：定完基调后，从主视觉里取 6-8 个主色写死，出完图统一做一次"调色板匹配"（`Image > Adjustments > Match Color` 或 ffmpeg/LUT），否则 40 张图拼起来会花。
3. **固定尺寸与构图**：同一类资源只用一个比例（立绘 3:4、单位 1:1、地块 1:1）。构图模板写进 prompt（"全身像，正面略侧 3/4 视角，脚底对齐下边缘"）。

### 5.3 各模块 Prompt 模板

**A. 武将立绘（3:4，900×1200）**

```
{风格锚}，
[角色]三国武将半身立绘，全身像，正面略侧 3/4 视角，站姿，
[服饰/兵器特征]，[表情]表情，
背景纯色（用于抠图），人物占画面 70%，
脚底对齐画布下边缘
```
> 角色描述示例：
> - 关羽：绿袍长髯、面如重枣、青龙偃月刀
> - 张飞：黑面虬髯、豹头环眼、丈八蛇矛
> - 赵云：白袍银甲、白马长枪、年轻英武
> - 刘备：双手过膝、耳垂及肩、仁厚面相、双股剑
> - 吕布：赤金甲、方天画戟、赤兔马、桀骜神情
> - 华雄：西凉重甲、大刀、凶悍

**B. 战场单位小人（1:1，192×192）**

```
{风格锚}，
三国战棋战场单位，[兵种/角色]，三分身到半身比例，
[武器]，正面朝向，站姿，脚底对齐下边缘，
背景纯色，中心构图，人物占画面 80%
```
> 兵种清单：刀兵（环首刀+皮甲）、弓兵（角弓+短甲）、骑兵（长枪+马铠）、枪兵
> 注意：**战场小人不要做成全身写实**（52px 格子里看不清），三分身比例最合适。

**C. 地形地块（1:1，104×104，可平铺）**

```
{风格锚}，
俯视 45 度中国古代军营地表，[草地/泥地/石地/木栅/土墙/寨门/高地]，
游戏地形贴图，无缝平铺，无阴影投在画面外，四边可拼接，
无文字，无人物
```

**D. UI 图标（1:1，128×128）**

```
{风格锚}，
游戏 UI 图标，[剑/盾/技能/声望/图鉴]，圆角方形底板，金色描边，
单一物件居中，透明背景，简洁易识别
```

### 5.4 出图到入库的管线

1. **出图**：按模板生成，统一 1024 以上分辨率
2. **抠图**：`rembg`（Python，本地免费）或即梦/稿定的一键抠图；要求边缘无白边
3. **规整**：裁到目标比例、人物脚底对齐下边缘、导出 PNG-24 带透明通道
4. **命名**：严格按第四节的 `{id}_{emotion}.png` / `{unit_id}.png` / `{tile}_{variant}.png`
5. **入库**：丢进对应目录即可 —— 立绘接口已做**缺图自动隐藏**，可以一张一张补、随时能跑
6. **Godot 导入注意**：`.import` 与 `.godot/` 已在 `.gitignore` 中；图片资源本身要提交（**别把 `assets/portraits/` 加进忽略规则**）

## 六、优先级与工作量

| 优先级 | 内容 | 数量 | 建议做法 |
|---|---|---|---|
| P0 | 4 名主角立绘（刘备/关羽/张飞/赵云）× 2 表情 | 8 张 | AI 出图，先定风格锚，这 8 张定完后全项目照抄风格 |
| P0 | 战场单位：4 主角 + 6 敌将 | 10 张 | 同风格，三分身比例 |
| P1 | 兵种小人：刀兵/弓兵/骑兵/枪兵 × 2 阵营 | 8 张 | 换色复用 |
| P1 | 地形：草地/泥地/高地/木栅/土墙/寨门 | 6-8 张 | 可平铺，先做这几样覆盖 4 关 |
| P2 | 其余敌将立绘（华雄/吕布/许褚/臧霸/昌豨） | 5×1 张 | 按需 |
| P2 | UI 图标替换 emoji | 10 张 | 或用 Kenney CC0 |
| P3 | 主菜单背景、章节封面图 | 4-5 张 | 每关一张，兼做宣传素材 |
| P3 | 音效/BGM | — | 用 CC0（Kenney / freesound） |

**成本估算**：P0 全部（18 张）用 AI 生图 + 抠图，控制在 **1 个工作日内**可完成；风格锚定的那 3-4 张试错是最耗时的部分，定完就快了。
