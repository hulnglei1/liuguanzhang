## 一、定位

三国穿越题材**战棋**（曹操传式格子战棋），核心是"原著梗 + 数值爽感"：
- 战场 12×10，格子 52px，1280×720，`canvas_items` 拉伸、`keep` 比例
- 我方 5–6 人 vs 敌方主将 + 杂兵
- 每关有**分阶段军令**（曹操传式胜利条件）

## 二、回合流程与操作（玩家最常问的）

### 2.1 一回合的顺序

```
我方回合开始
  ├─ 结算：玉米种子回血 → 桃园结义回血（每回合 5 HP）→ 士气结算
  ├─ 逐单位行动：选中 → 移动 → 行动（攻击 / 绝技 / 待机 / 合体）
  └─ 判定：全部单位行动完 → 自动进入敌方回合（会有横幅提示）

敌方回合
  ├─ 铁皮等状态衰减
  ├─ 每个敌军按 AI 选目标（关羽蓄力 ≥10 时全军扑他）
  └─ 全部行动完 → 回到我方回合
```

> **注意**：我方**全员行动完毕会自动结束回合**，不需要手动点"结束回合"。系统会先弹横幅「✅ 我方全员行动完毕 → 敌方回合」，不会无声跳过。

### 2.2 按键表

| 操作 | 效果 |
|---|---|
| **鼠标左键** | 选中单位 / 点绿格移动 / 点敌人攻击 / 点技能目标 |
| **鼠标右键** | 取消当前选择、返回上级菜单 |
| **空格** | ① 有剧情对白时 → 推进下一句<br>② 张飞喊字中 → 累加字数<br>③ 平时 → **结束我方回合**（若还有未行动单位，**先警告，再按一次才确认**） |
| Esc / 取消指令按钮 | 同右键 |

> 空格的三重含义按优先级判定：对白 > 喊字 > 结束回合，不会互相干扰。

### 2.3 行动规则

- 每单位每回合可：**移动一次 + 行动一次**（攻击/绝技/待机）
- **"已移动"是单位级状态**（`moved_this_turn`，写在 BattleUnit 上），换人、重选都不会绕过；撤回移动后可重新移动
- 移动后仍可攻击（曹操传手感）；移动后可用「撤回移动」退回
- `待机休整` = 消耗本次行动，直接结束该单位
- 单位阵亡后不可再操作

**"已行动"（acted）的严格约束 —— 任何入口都必须拦住**

- 已行动的我方单位：**点击只做查看**（右侧面板显示信息），不进入任何可操作态
- 三条防线，缺一不可：
  1. `_handle_click` 统一前置：点到已行动我方单位 → 直接 `_inspect_unit`，不进状态机
  2. `_select_unit` 纵深防御：命中已行动单位直接拒绝（防止未来新增入口绕过）
  3. `_do_move` / `_show_command_menu` 兜底：已行动单位不可移动、不留可见命令菜单
- `_inspect_unit` **不得**设置 `input_mode = SELECT`（历史 bug：只是查看却进入可操作态，
  导致"点一下放完技能的武将，再点地面就能让他移动"）

## 三、核心机制数值

### 3.1 关羽【千里青龙斩】

| 蓄力 | 倍率 | 贯穿 | 特殊 |
|---|---|---|---|
| 0–4 格 | 0.5–1.7x | 1–2 格 | — |
| 5–9 格 | 2.0–3.2x | 4 格 | 敌军开始被吸引（6 格内） |
| 10–14 格 | 3.5–4.1x | **12 格** | **可劈开城门**（+500 声望） |
| 15 格（不骑乘上限） | 5.25x | 12 格 | — |
| **20 格（骑赵云上限）** | **7.0x** | 12 格（一线到底） | 传说档【裂地千里】 |
| 20 格 + 双子合击 ×1.5 | **10.5x** | — | **可秒杀任何主将** |

- 蓄力增长：每移动 1 格 +1（骑乘同样 +1，不加速；骑赵云只是 mov 从 4 变 6）
- **受击清零**：关羽被打中，蓄力全部归零（原著"气脉震散"）
- **合体护航**：骑赵云时**首次受击不清零**，每关仅一次
- 劈城门：必须把技能目标点成**城门格**，且蓄力 ≥10；否则提示"力道不足"

### 3.2 张飞【燕人咆哮】

| 字数 | 效果 | CD |
|---|---|---|
| 六字「燕人张飞在此」 | 1.6x 伤害、眩晕 1 回合、半径 2、仅敌方 | 3 回合 |
| 十四字「…谁敢与我决一死战」 | 2.4x、眩晕 **2 回合**、半径 3、**敌我不分**（己方也晕 1 回合，只晕不伤） | 5 回合 |

- **操作**：点「咆哮」按钮 → **直接开喊**（不需要点目标）→ 4 秒窗口内连点左键/空格累加字数 → 右键或窗口结束即释放
- 佩戴【静音耳塞】后，己方不会被十四字波及

### 3.3 吕布【方天乱舞】

- 每挥舞第三下：**前三击力量叠加 ×3**，并激活**两息铁皮**（免疫一切伤害）
- 铁皮只在"第三击"的那一瞬有效，**张飞的咆哮可以直接震碎**
- 我方每阵亡一人，吕布获得暴怒加成（多打少惩罚）

### 3.4 赵云【无限耐力】

- mov 6（全队最高）；行动结束自愈 15% HP
- 普攻每 2 次追加一次突刺（百鸟朝凤）
- 可与关羽【合体】：关羽骑乘后 mov 变 6、普攻触发 1.5 倍双人合击

### 3.4.1 公孙瓒【白马·定速回旋飞弹】

- 可锁定**全图任意敌军**（无距离限制）
- **相邻 1 格**：当回合直达命中
- **2 格及以上**：射出飞弹，每回合朝目标推进 **3 格**，追上才结算伤害
- 目标在飞行途中阵亡 → 飞弹自然消散
- 冷却：见 `scripts/entities/skills.gd` 中 `meta("arrow_rain").cd`

> 注意：这里曾经是"3 格内立即命中"，导致玩家在全图点选时看到"箭根本没射出去"——已改为 1 格。

### 3.5 将缘（羁绊）

| 将缘 | 条件 | 效果 |
|---|---|---|
| 桃园结义 | 刘关张同阵 | 开局士气 +10，每回合全体回 5 HP |
| 白马义从 | 公孙瓒 + 刘备 | 公孙瓒攻击 +15% |
| 云长为马 | 关羽 + 赵云 | 解锁合体技 |

### 3.6 士气

- 士气影响攻防倍率（`MoraleCore`）；不应战/被挑战失败会掉士气
- 面板实时显示"我方 X vs 敌方 Y（攻防修正 ×a / ×b）"

## 四、关卡与军令（胜利条件）

**规则**：每关由 `data/chapters/chapterN.json` 的 `stages` 数组定义，逐阶段判定，**全部达成才通关**；我方全灭即失败。

| 关 | 阶段 1 | 阶段 2 | 原著依据 |
|---|---|---|---|
| 1 汜水关 | 斩华雄 `kill_commander` | 劈开城门 `break_gate` | 斩将后袁绍下令攻城 |
| 2 虎牢关 | 坚守 3 回合 `survive_turns` | 击退吕布 `defeat_commander` | 吕布撤回关内，关没破 |
| 3 谯县 | 肃清乱兵 `kill_minions` | **招降许褚**（打到三成血）`recruit_at_hp` | 许褚是被招揽的 |
| 4 泰山郡 | 击破昌豨 `kill_target` | 击退臧霸 `defeat_commander` | 打回琅琊郡 |

**战败**：我方全灭 → 置 `defeat` 标记 → 停止一切操作 → 播失败对白 → 对白播完自动回主菜单。
（此前只播对白不置标记：全灭后回合会无限空转、失败对白反复播放，玩家只能强退）

条件引擎支持的全部类型见 [原著速查](原著速查.md) 第三节。

### 4.5 剧情事件的战场效果（events.effect）

**原则：剧情描写必须与单位状态一致。** 剧情说某人被打了，他的血条就得真的掉。

`data/chapters/chapterN.json` 的 `events[]` 支持可选的 `effect` 字段，在播放对白前结算：

```json
{ "turn": 3, "type": "dialog", "key": "chapter2_wuanguo_fall",
  "effect": { "kind": "smash_unit", "target": "wuanguo", "by": "lubu",
              "mult": 3.0, "hp_floor_ratio": 0.3, "exhausted_turns": 3 } }
```

| 参数 | 含义 |
|---|---|
| `kind` | 效果类型。目前支持 `smash_unit`（被三倍暴击打飞） |
| `target` / `by` | 受害者 / 施暴者 |
| `mult` | 伤害倍率（3.0 = 方天画戟第三击） |
| `hp_floor_ratio` | **保底血量比例**：最多打到只剩这个比例，保证剧情不会把单位打死 |
| `exhausted_turns` | 脱力持续回合数（脱力 = DEF-30%） |

**已应用**：第 2 关第 3 回合「武安国被吕布打飞」——实测 HP 160→66、DEF 12→8、脱力 3 回合、不会阵亡
（原著：倒飞十几米，当场吐血脱力，是被抬下去而非战死）。

**脱力机制**：`unit.exhausted_turns` 记录剩余回合，回合结束递减。
武安国自己挥锤是 1 回合（旧机制不变），被吕布打飞是 3 回合。

## 七、美术资产规范

见 [美术资源规范与 AI 生图指南](美术资源规范与AI生图指南.md)，要点：
- 立绘 `assets/portraits/{unit_id}_{emotion}.png`（900×1200）
- 单位静态图 `assets/units/{unit_id}.png`（192×192）
- **缺图自动回退色块**，可一张一张补；新增 PNG 必须让 Godot 导入一次

### 7.1 单位序列帧动画

| 动画 | 目录 | 播放方式 |
|---|---|---|
| **呼吸/待机** `idle` | `assets/units/{unit_id}_idle/0.png 1.png …` | **循环**，3 fps |
| **攻击** `attack` | `assets/units/{unit_id}_attack/0.png 1.png …` | **单次**，10 fps，播完自动回 idle |

- 帧文件按 `0.png / 1.png / …`（或 `00.png`）编号，遇到断档即停止加载
- **只有 idle 或只有 attack 也能用**：缺哪个就用另一个/静态图占位，不会报错
- 两个目录都没有 → 回退静态图 `{unit_id}.png` → 再没有就回退色块 + 书法字
- 攻击时的表现：**朝向自动翻向目标** + 前冲 14px 回弹（打击感），这段是代码做的，不需要美术出

> 实现位置：`scripts/ui/unit_art.gd:load_frames_for()` 构建 SpriteFrames；
> `battle.gd:_make_unit_node()` 挂 AnimatedSprite2D（节点名 `ArtAnim`）；
> `battle.gd:_play_unit_attack_anim()` 负责切 attack / 翻转朝向 / 冲刺位移。
> 验证脚本：`tests/probe_anim.gd`
