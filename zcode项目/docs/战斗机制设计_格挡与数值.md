## 〇、一句话目标

**普攻是菜鸡互啄，技能是破局手段，位置与时机决定胜负。**
敌人靠数量与分拨制造压力，不靠单点血厚。

这条决定了一切取舍：
- 普攻伤害要低到"打杂兵都要三四刀"，玩家才被迫动脑用技能
- 技能要有明确的分工（控场 / 清线 / 收割），不能人人都能一键清场
- 敌人要多、要分拨，让"选哪个方向打"成为决策

## 一、角色定位（谁负责什么）

| 单位 | 定位 | 强度来源 | 弱点 |
|---|---|---|---|
| **张飞** | **控场** | 14 字咆哮：半径 2、眩晕 2 回合、敌我不分 | 几乎打不死人（6 字 13 伤 / 14 字 23 伤） |
| **关羽** | **清线** | 青龙斩贯穿直线 + 蓄力（移动即蓄力） | 蓄力被打断就清零；mov 只有 4 |
| **赵云** | **续航收割** | 无攻击绝技 → 全靠基础盘：**mov 6（全场最高）+ 每回合自愈 15% + 每 2 次普攻追击 + atk 30** | 没有爆发，杀主将慢 |
| **公孙瓒** | **远程压制** | 慢速绕后箭（多支累积，从任意方向来） | 被贴身就废（atk 22、def 9） |
| **刘备** | **指挥/诱饵** | 士气、合体、系统 | **平砍最弱（atk 12）**，不能当输出用 |
| **许褚** | 敌·爆发 | 裸衣：攻速翻倍 + 吸血，但 DEF 腰斩 | 血少，怕集火 |
| **吕布** | 敌·机制 | 方天三击 + 铁皮 | 怕张飞咆哮破铁皮 |

### 赵云的补偿设计（重点）

他没有攻击性绝技，如果只靠"自愈 + 机动"，很容易变成"最没存在感的角色"。建议再加一条被动：

> **【常山铁壁】每回合第一次受到的伤害 -30%**

理由：原著里赵云的核心是"无限耐力、冲阵不死"，减伤比加攻更贴人设，也让他敢单独钻进后排。**成本约 5 行代码**（在 `take_damage` 里加一个每回合一次的标记）。

## 二、数值

### 2.1 分层

| 层 | HP | ATK | DEF | 说明 |
|---|---|---|---|---|
| 主角（关/张/赵） | 110-150 | 30-32 | 10-14 | 打杂兵 2-3 刀 |
| 主角（刘备） | 90 | **12** | 10 | 比杂兵略强，不能当输出 |
| 主角（公孙瓒） | 130 | 22 | 9 | 远程，近身弱 |
| 敌方主将 | 200-260 | 28-36 | 12-16 | **普攻打不动**，必须技能/破防 |
| 杂兵 | 45-65 | 9-13 | 4-6 | 2-4 刀一个，靠数量 |

### 2.2 关键判断

- **不削杂兵血**（原计划 65→50 已取消）。理由：普攻就该是菜鸡互啄，削血会让普攻变强，反而削弱技能价值。
- **主将血量下调 10-15%**（许褚 280→240、典韦 300→260）：难度回到机制（铁皮/裸衣/三击），不是磨血条。
- **弓兵攻击低于刀兵**（13 vs 13 持平，不再高于）：远程已占射程便宜。

## 三、格挡

| 项 | 设计 |
|---|---|
| 触发 | 普通攻击、飞行箭矢 |
| 不触发 | **绝技**（对应潘凤"穿透防御，任他如何格挡也无用"） |
| **前置条件** | **仅当目标 DEF ≥ 攻击方 ATK 时才判定** ← 关键：杂兵之间几乎不触发，只有打高防主将才出现 |
| 概率 | `clamp(0.05 + (def - atk) × 0.01, 0.05, 0.30)` |
| 效果 | 伤害 ×0.5（至少 1） |
| 表现 | 浮字「铛！格挡」+ 金属音 + 白闪，战斗纪要写一行 |

**为什么加前置条件**：不加的话，菜鸡普攻会被进一步削弱，战斗变成互相挠痒；加了以后，格挡变成"打 Boss 时的额外阻力"，正好强化"必须用技能破局"。

原著依据：吕布格挡张飞蛇矛（"连忙格挡"）、张飞强行格挡第三击（仍倒飞）、刘备挡住一击（双腿瘫软）——**减伤有代价，不是免疫**。

## 四、地图 / 镜头 / 小地图 / 分拨

### 4.1 现状硬约束

- 棋盘可用区 624×520；12×10 @52px = 624×520，**正好顶满**
- 右侧面板从 x=652 起，底部纪要从 y≈586 起
- 要更多纵深，必须**镜头滚动**，不能只缩格子

### 4.2 目标

| 项 | 设计 |
|---|---|
| 地图 | **18×12**（世界 936×624，横向可滚 312px） |
| 镜头 | 方向键/WASD + 鼠标推到屏幕边缘 + 小地图点击跳转；边界夹取 |
| 小地图 | 右下角 18×12 缩略，敌我色点，当前视口框 |
| 分拨 | 敌人带 `wave` 分组；**未激活组完全不动**；触发条件：我方进入 N 格 或 前一波清空 |

### 4.3 技术要点（翻车点）

- UI 在 `CanvasLayer`，不随镜头滚动 ✅
- 棋盘内容在 `MapRoot / UnitRoot / Overlay` 三个 Node2D → 加 `Camera2D` 即可整体平移
- **输入坐标**：`event.position` 是屏幕坐标，`_px_to_cell` 要世界坐标 → 统一用 `get_global_mouse_position()`
- 地面贴图要从 1248×1040 重生成到 1872×1248（脚本已有）

### 格挡的实际公式（与最初方案不同，已修正）

```gdscript
static func block_chance(atk: int, def: int) -> float:
	if def <= 8:                       # 杂兵永不格挡（否则菜鸡互啄被拖长）
		return 0.0
	return clampf(0.05 + (def - 10) * 0.03 - (atk - 20) * 0.005, 0.03, 0.30)
```

实测：关羽(32)打吕布(14) = **11%**；刘备(12)打吕布 = **21%**（弱者更容易被挡）；
关羽打杂兵(def 8) = **0%**。300 次采样实测 34 次格挡，与期望一致。

> 最初写的是"防御 ≥ 攻击才格挡"，验算后发现**永远不会触发**（主角攻击 30-32 高于所有敌人防御 14-16）。改成了现在的档位公式。
