## 四、打磨改动（体验优化）

### 操作方式重构（解决「不会玩」）
- **命令菜单**：选中武将后弹出【移动 / 攻击 / 技能 / 待机】按钮（替代原来全靠猜的点格子）
- 攻击/技能按钮按当前可目标动态显示，技能显示冷却状态
- **新增「待机/蓄力」**：修复了张飞咆哮蓄力无法触发的 bug（此前断桥怒吼的眩晕核心机制根本放不出）

### 反馈与动画（解决「没手感」）
- **走格动画**：单位沿格子平滑移动（Tween）
- **伤害飘字**：受击位置飘「-伤害」数字
- **技能演出**：关羽「千里·青龙斩」横幅+爆点、张飞「燕人咆哮」音波圈、阵亡大字
- **敌方行动演出**：敌回合横幅、出手前目标高亮、逐步推进（看清谁打了谁）

### 叙事与流程（解决「没闭环」）
- **胜利结算面板**：显示获得声望/图鉴/战利品 + 【下一关】【返回主城】按钮（通关后可直接续关）
- 战斗日志每回合重置，不再无限累积

### 战斗爽感升级（把核心爽点做到极致）
- **关羽·青龙斩**：满蓄力触发**全屏闪光 + 震屏 + 「千里·青龙斩！！」定格口号 + 横贯全屏的青龙刀光带**
- **张飞·燕人咆哮**：多层音波圈向外扩散 + 震屏
- **赵云·七进七出**：沿路径残影连闪
- **许褚·裸衣**：「裸衣！死战！！」大招演出 + 红色震屏 + 爆甲范围圈 + 我方被爆甲单位震动
- **公孙瓒·拐弯箭雨**：范围音波圈（此前玩家侧无法释放，已补技能分支）
- **通用爽点**：受击单位弹跳、击杀主将时「大招定格」（震屏+闪光+大字）
- **连携演出**：眩晕时「被控住！快集火！」横幅提示，强化「张飞控→集火」组合技
- **抽奖惊喜**：抽中金光扫屏 + 结果文字弹跳（武器池更高档双闪）

### 玩家评审驱动的修复（修复「写了没生效」+ 打破套路化）
> 由 4 位不同画像的玩家 agent 评审，其中核心玩家/收集党通过源码分析发现 3 个真实缺陷（已逐一核实），据此修复：

**P0 修复「写了没生效」的空洞（让成长系统成立）**
- **装备/抽奖真正进战斗**：抽到的金刚护腕(+防)、古兽护符(+血)、番薯(攻+10%)、玉米(每回合回血)、土豆(开局士气) 现会实际加成到战斗数值
- **修复吕布·方天乱舞**：连击改跨回合累积（越战越勇），只有被打晕才打断（此前第3击永远触发不了）
- **修复武安国·三倍巨力**：被动现实际 ATK×3（此前是死的）

**P0 新手引导**：首次游玩自动弹教学对话（点武将/命令菜单/蓄力/组合技），右上角常驻「? 帮助」按钮

**P1 打破「张飞咆哮+集火」唯一解**：第8回合起敌方援军压境、敌方加攻，制造节奏压力，逼玩家换打法/速战
**P1 原著还原修正**：张飞找回「审慎谋定」性格、许褚收服补「赐马赐甲」自洽、胜利收尾差异化
