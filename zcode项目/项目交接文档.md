## 一、项目由来与选型决策（历史背景）

用户有一部网文《魂穿刘关张，诸侯们被整麻了》（蓝色三角形，GB18030 编码，原文在父目录 `魂穿刘关张，诸侯们被整麻了.txt`），想把其改编成游戏，且希望**用 AI agent 工具驱动的方式来开发**。

### 关键选型决策（都是已拍板，勿推翻）
| 决策 | 结论 | 理由 |
|---|---|---|
| 游戏模式 | **曹操传式关卡战棋（SRPG）** | 最适合承载反转叙事+沙雕对白+武将技组合机制 |
| 开发方式 | **从零做，不用 MOD 编辑器** | MOD 做不了蓄力/组合技等自定义机制，且素材有版权 |
| 技术栈 | **Godot 4.7.2 + GDScript** | 2D 战棋成熟、可导出 Web、廉报价、GDScript 对 AI 生成友好 |
| 内容原则 | **机制层提炼成玩法，喜剧文本层保留原味** | 小说反转/吐槽不能提炼否则死，机制可 1:1 变系统 |
| 版权 | 技能用「原创但同构」，不照搬小说技能名/大段文字 | 自用 Demo 可引原对白，公开发布需换 |

## 四、玩家试玩验证（3 个体验 agent，已完成）

> 用 3 个玩家 agent（核心向/休闲向/爽感向）**实际运行 Godot、走完整流程**（剧情→操作→技能→通关→抽奖→图鉴），以「真实体感」反馈。
> **其中两个 agent 独立发现了一个致命 bug（见下方 P0），已核实并修复** —— 这是试玩最大的价值。

### 🔴 P0 致命 bug（试玩暴露，已修复）
**现象**：正常击杀敌方主将后，胜利结算面板不弹出、声望/图鉴/抽奖整条 meta 闭环「打赢也拿不到」。我在验收时漏掉了这个（无头测试只测机制、未测端到端通关触发链）。

**根因**（两处，都在 `scripts/battle.gd`）：
1. 对话 JSON 是 `{"dialogs":{...}}` 外壳，但 `_load_chapter` 未解包 → `dialogs[key]` 取到的是嵌套字典而非对白数组 → **所有剧情/胜利/失败对白都不播**
2. 代码用 `chapter_id+"_open/_win/_lose"`（chapter1_open）查 key，但数据 ch1/ch2 存的是 `ch1_open` → key 对不上

**修复**：`_load_chapter` 解包 `{"dialogs":{...}}` ＋ 把 4 个对话文件 key 统一成 `chapter<N>_open/_win/_lose`（对齐 chapter_id）。

**回归保护**：新增 `tests/test_e2e_win.gd` —— 真实验证「击杀主将→胜利对白→结算面板→战利品入背包→通关记录写入」端到端链路，防再犯。（教训：**背靠背地测「机制」和「端到端触发链」两类测试**）

### ✅ 核心向反馈
- **爽点**：满蓄力龙斩（全屏+震屏+定格口号一刀秒华雄）「身体有反应」；张飞吼晕+青龙斩组合技到位；收许褚变强实感真
- **痛点**：【高】开局对话长要点十几下才开打；【高】满蓄力龙斩「差一格就成小水花」（charge8-9 无全屏高光）；【中】四关同一招「吼晕+集火」唯一解；【中高】装备「+6防/+40血」无视觉实感（就一行小字）；【中】图鉴无立绘
- **只改一件事最爽**：让满蓄力大招成为玩家每次都追的峰值（接近满给高光预告、蓄满攒「龙魂」）

- **中**：图鉴/抽奖的「还想再来一发」钩子因 bug 尝不到；画面仍色块、卖相撑不起「哇」

## 五、技术架构与约定（接手必读）

```
zcode项目/
├── project.godot          # 入口（Godot 4.7）
├── scenes/                # battle/main/lottery/gallery
├── scripts/
│   ├── core/              # grid/combat/turn（纯逻辑，可无头测试）
│   ├── entities/          # unit/skills（单位与技能）
│   ├── systems/           # morale/lottery/save
│   ├── battle.gd          # 战斗主控（接线渲染+逻辑）
│   ├── main.gd            # 主菜单
│   └── lottery_ui.gd, gallery_ui.gd
├── data/                  # 数据驱动（units/chapters/dialogs/collection JSON）
├── tests/                 # 11 套无头自动化测试
├── assets/fonts/          # 中文字体（SimHei/msyh）
└── docs/ 程序经验笔记.md   # Godot 踩坑记录
```

### 关键架构约定
1. **纯逻辑 / 渲染分离**：core 只跑算法返回事件数组，不碰节点；battle.gd 接线到渲染
2. **数据驱动**：数值/对白全在 `data/*.json`，改数值不动代码
3. **跨脚本引用用 preload 常量**（Godot headless 下 class_name 全局注册有坑，勿依赖全局类名）
4. **中文字体**：必须打包，否则方块字（theme.tres 全局生效）
5. **敌人 AI**：确定性脚本（boss 技能、兵种行为），未接 LLM

## 八、对新手/协作的重要提示（易踩坑）

- **改 `.tscn` 后**：可能因 `.godot` 缓存旧场景，跑一次 `--headless --import` 强制刷新

- **用户存档**在 `%APPDATA%\Godot\app_userdata\魂穿刘关张 · 战棋\save.json`，测试完记得清，让玩家从 0 开始
