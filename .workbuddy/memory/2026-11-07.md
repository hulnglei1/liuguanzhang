## 追加（同日）：批次 1 已完成

### 地面连续性（用户二次反馈："看起来不那么连贯"）
**根因**：按格子贴 104×104 贴图 = 每格把图案重置一次，格与格之间必然对不上。
**改法**：`tools/gen_ground.py` 生成**一整张 1248×1040 连续地面**（多倍频平滑噪声 + 土斑 + 草叶 + 暗角），
`_draw_grid()` 只铺一张 TextureRect，格线降到 7.5% 透明度。
顺带把障碍物从纯灰方块换成程序化石砖（wall.png）/铁木城门（gate.png），去掉 emoji 换纯文字。

### 音频闭环
- `tools/gen_bgm.py` 程序化合成 3 首五声音阶循环曲 → ffmpeg 转 OGG（26.7s/20s/9s，共 312KB）
- `scripts/systems/audio_director.gd` 注册为 **Autoload**：
  - 运行时建 Master/BGM/SFX 三条总线
  - 双播放器交叉淡入淡出，切场景不断音乐
  - `user://settings.json` 持久化音量与全屏
- `main.gd`：右下角「⚙ 设置」面板（3 条滑条 + 全屏开关 + 关闭）
- `battle.gd`：进关播 battle，胜利切 win

### 踩坑（重要）
1. **残留 Godot 进程会占住 9099 端口**，新实例降级到文件 IPC，于是 RPC 打到**旧进程**上，
   表现为"代码明明改了却报 Unknown RPC method"。排查方法：看日志有没有「TCP 监听失败」，
   并用 PowerShell 按 PID 强杀（`taskkill //IM` 有时杀不掉）。
2. **全屏模式下 MCP 注入的点击坐标对不上**，切全屏后点界面会失效（真实鼠标正常）。
   自动化验收保持在窗口模式。
3. UI 树 dump 原本只收 Button/Label/ProgressBar，**HSlider 不在里面** —— 已补上，
   否则"设置面板有 3 条滑条"这种验收会假阴性。
