### 踩坑（重要）
1. **残留 Godot 进程会占住 9099 端口**，新实例降级到文件 IPC，于是 RPC 打到**旧进程**上，
   表现为"代码明明改了却报 Unknown RPC method"。排查方法：看日志有没有「TCP 监听失败」，
   并用 PowerShell 按 PID 强杀（`taskkill //IM` 有时杀不掉）。
2. **全屏模式下 MCP 注入的点击坐标对不上**，切全屏后点界面会失效（真实鼠标正常）。
   自动化验收保持在窗口模式。

   否则"设置面板有 3 条滑条"这种验收会假阴性。
4. **`--script` 模式下 Autoload 不是全局标识符**（最坑的一个）：
   脚本里直接写 `AudioDirector.xxx` → 编译报 `Identifier not found: AudioDirector`，
   而编辑器/正常运行都正常。症状是**整批测试超时**（场景加载失败、进程不退出），
   日志里只会看到 TIMEOUT，看不到根因。
   **正确写法**：`var ad = get_node_or_null("/root/AudioDirector")` + 非空判断。
   已写入《测试用例.md》第六节第 3 条。

## 追加四：环境坑 —— git 推送挂死（不是网络问题）

**症状**：`git push` 挂住不报错；重试报 `schannel: server closed abruptly (missing close_notify)`。

**排查过程**：
1. `curl https://github.com` → 200（代理 127.0.0.1:7897 正常、直连也正常）→ **不是网络**
2. `GIT_CURL_VERBOSE=1` → CONNECT 隧道建立成功，卡在 TLS 握手
3. `GIT_TRACE=1` → 最后一条是 `git credential-helper-selector get` → **卡在凭据助手**
4. `git credential fill` 直接挂死 → 确认

**根因**：PortableGit 自带的 `helper-selector`（在 `etc/gitconfig`，系统级）会尝试拉起
GUI/askpass 询问，非交互环境下永远等下去。

**修法**（已永久写入 `~/.gitconfig`）：
```bash
git config --global --unset-all credential.helper
git config --global --add credential.helper ""        # 空值 = 清空之前的所有 helper
git config --global --add credential.helper wincred   # 直接用 Windows 凭据管理器
```
空值那一行是关键——它把系统级的 `helper-selector` 顶掉。
验证：`git ls-remote origin` 立刻返回。

> 临时绕过：`git -c credential.helper= -c credential.helper=wincred push`
> **教训**：git 命令"卡住无输出"时，先怀疑凭据助手，别一上来调 SSL 后端。
