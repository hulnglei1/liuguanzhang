# 《魂穿刘关张，诸侯们被整麻了》 · 游戏化项目

基于小说「魂穿刘关张，诸侯们被整麻了」（蓝色三角形）的**曹操传式战棋**游戏化项目。

## 设计决策（已定）

- **游戏模式**：曹操传式关卡制战棋（SRPG）——最适合承载小说的反转叙事 + 搞笑对白 + 武将技组合机制。
- **开发方式**：从零开发，**不用**曹操传 MOD 编辑器（机制无法自由定制、素材有版权、仅 PC 可跑）。
- **技术栈**：HTML5 Canvas + 原生 JS（ES Modules），无框架无构建，浏览器直开。
- **内容原则**：机制层提炼成玩法，喜剧文本层保留原味；技能为「原创但同构」规避版权。

## 开发路线

1. **M0 垂直切片**：第一关《逃兵·温酒斩华雄》全流程可玩（蓄力/士气/骑乘/抽奖跑通）
2. **M1**：+3 关（三英战吕布/裸衣许褚/长坂坡），赵云吕布加入，武器池开
3. **M2**：完整抽奖池、图鉴、成就、事件文本库
4. **M3（可选）**：战场升级「三国群英传式」半即时，保留武将技核心

## 怎么跑起来

- 代码就位后：双击 `index.html` 即可在浏览器游玩（推荐 Chrome/Edge）。
- 需要本地服务器时：`python -m http.server 8000` 后访问 `http://localhost:8000`。
