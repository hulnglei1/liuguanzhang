## 五、产出与验收流程（固化）

```
AI 出图（1024×1024，透明底）
  → normalize_to_reference.py（rembg 抠图 + 按关羽包围盒对齐 + 去水印裁切）
  → assets/units/{id}.png 或 assets/portraits/{id}_normal.png
  → Godot --import
  → tests/probe_art_coverage.gd（覆盖率门禁）
  → 进游戏逐关截图肉眼验收
```

**验收门禁（自动化）**：`probe_art_coverage` 会检查"关卡里出现的每个单位都有贴图""每位台词主将都有立绘"，
缺一张就 `[FAIL]`——避免悄无声息地退化成色块。
