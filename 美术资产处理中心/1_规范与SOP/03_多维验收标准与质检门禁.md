# 03. 多维验收标准与质检门禁

> 验收核心原则：**能用代码检查的坚决不靠肉眼，必须靠肉眼的形成对照清单。**
> 任何资产必须通过 **三级门禁（L1 机器硬门禁 -> L2 视觉审美门禁 -> L3 游戏交互门禁）** 方可合入主线。

---

## 门禁分级总览

```
[待检资产] ──► [L1: 自动化机器硬指标] ──FAIL──► 打回重跑 normalize_art.py / 重新裁切
                      │ PASS
                      ▼
              [L2: 视觉风格质感软指标] ──FAIL──► 局部重绘 (Inpaint) / 重新垫图生图
                      │ PASS
                      ▼
              [L3: 引擎实机运行与体验] ──FAIL──► 调整锚点 / 调整缩放 / 代码修正
                      │ PASS
                      ▼
                 【正式入库】
```

---

## 一、L1 级：自动化机器硬门禁（100% 脚本拦截）

由 `tools/check_art.py` 严格判决，出现任何一个 `FAIL` 项禁止入库：

| 校验维度 | 判定指标 | 战场单位 (Units) | 剧情立绘 (Portraits) | 地块 (Tiles) | 违规后果 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 命名规范** | 正则匹配 | `^[a-z0-9_]+\.png$` | `^[a-z0-9_]+_(normal\|angry\|happy\|sad\|shock)\.png$` | `^[a-z0-9_]+_\d{2}\.png$` | 引擎无法动态映射资源 |
| **2. 画布尺寸** | 像素精度 | **必须严格 192 × 192** | **必须严格 900 × 1200** | **必须严格 104 × 104** | 画面撕裂、切换闪烁 |
| **3. 脚底贴底** | 离画布底边间距 | **≤ 8 px** | **≤ 10 px** | N/A (满铺) | 角色悬空浮起或陷入地下 |
| **4. 水平居中** | 角色重心偏离度 | **≤ 3.0%** (推荐 ≤ 1.5%) | **≤ 3.0%** (推荐 ≤ 1.5%) | N/A (居中无意义) | 换人或行走时左右突跳 |
| **5. 高度占比** | 人物高度 / 画布高度 | **78% ~ 96%** (标准 88%) | **72% ~ 95%** (标准 83%) | N/A | 人物高矮比例失真 |
| **6. 半透明边缘** | 半透明过渡像素占比 | **< 3.0%** (超过 8% FAIL) | **< 3.0%** (超过 8% FAIL) | **0% (必须纯实心)** | 深色背景泛白色光圈（脏边） |
| **7. 安全边缘** | 离画布四边空白 | **四周各留 ≥ 4 px** | **四周各留 ≥ 6 px** | **0 px (边界严密贴合)** | 武器刀尖、头盔发丝被硬切断 |

## 二、L2 级：视觉风格质感软门禁（AI 评审 / 人工核验）

通过母版与风格锚对比核验，确保整套美术风格高度自洽：

### 1. 艺术风格与材质核验
- [ ] **工笔重彩与水墨底蕴**：线条硬朗挺拔，人物受光面具备油画厚涂与重彩感，暗部有水墨渐变质感，无廉价二次元平涂感。
- [ ] **金边勾线质感**：盔甲缝隙、肩甲边缘、兵刃锋刃处有细致的高光金线/反光，提亮暗色调画面。
- [ ] **排斥现代与异域违和感**：严禁出现西洋板甲、哥特花纹、现代军靴、奇幻发光翅膀等不符合三国时代的元素。

### 2. 阵营与色板核验
- [ ] **我方角色（刘关张赵等）**：色调以“深墨色、青绿、天蓝、银白”为主基调，透出正统与英武之气。
- [ ] **敌方角色（华雄、吕布、西凉军）**：色调以“暗红、铁黑、深褐、紫金”为主基调，透出嗜血与狂暴威压。
- [ ] **中立/盗匪（泰山贼、黄巾余部）**：兽皮麻布、粗布草鞋、灰土与褐黄色系。

### 3. 解剖与肢体完整性核验
- [ ] **手部五指健全**：握持兵器（青龙刀、蛇矛、双股剑、方天画戟）的手势自然，无多指、融指、断指。
- [ ] **兵刃特征还原**：
  - 关羽：青龙偃月大刀，刀头厚重带回钩。
  - 张飞：丈八点钢蛇矛，矛尖弯曲如游蛇。
  - 刘备：双股鸳鸯剑。
  - 赵云：亮银长枪，白袍银甲。
  - 吕布：方天双耳画戟，束发金冠，红锦百花袍。

## 三、L3 级：引擎实机运行与体验门禁（真机运行）

在 Godot 1280×720 视口中实机挂载后的验收要点：

### 1. 棋盘单位 (Units) 实机体验
- [ ] **52px 格子下辨识度**：缩放至棋盘尺寸时，角色轮廓、头部发冠、武器识别度清晰，不糊成一团色块。
- [ ] **脚底对准网格**：角色脚下红蓝阵营指示圆环正好处在脚底着力点，无漂浮感。
- [ ] **血条与名牌避让**：角色头顶装饰或高缨不得挡住头顶悬浮的 `HPBar` 血条。
- [ ] **行走补间平稳**：Tween 走格时，角色图片无左右摇摆和上下异常抖动。

### 2. 剧情立绘 (Portraits) 实机体验
- [ ] **对话框立绘摆放**：立绘在对话框左侧/右侧滑入时，头面部处于屏幕上层视觉焦点，不被底边文字框遮挡五官。
- [ ] **表情平滑切换**：同角色从 `normal` 切换到 `angry` 时，身躯、肩膀、盔甲完全静止，只有面部表情变化，无明显“闪身”跳变。
- [ ] **图鉴界面居中**：在【诸侯图鉴】大图详情展示时，全身立绘高光居中，比例舒展大方。

## 四、一票否决项（FATAL FAIL）

如出现以下任何一项，该资产**直接废弃，不得入库**：
1. 角色带有任何 AI 水印、文字残余、签名假字。
2. 抠图边缘有大片实心灰白背景残留。
3. 棋盘单位朝向朝左（背对敌方，导致战场上敌我对视错乱）。
4. 兵器穿透身体或肢体严重畸形。
